# 🌸 Petal & Poá

**Um carinho em forma de flores.**

Petal & Poá é um projeto de site para uma floricultura fictícia, desenvolvido com HTML5 e CSS3. A proposta é criar uma experiência visual delicada, elegante e acolhedora, apresentando buquês e transmitindo a ideia de que pequenos gestos podem se transformar em lembranças especiais.

O projeto foi desenvolvido com foco no aprendizado e na prática de desenvolvimento front-end, desde a estruturação do conteúdo até a criação de um layout responsivo.

## ✨ Funcionalidades e características

- **Layout responsivo:** adaptação do conteúdo para diferentes tamanhos de tela.
- **Menu de navegação:** navegação com menu adaptado para dispositivos móveis.
- **Seção de apresentação:** destaque para a identidade visual e a proposta da floricultura.
- **Catálogo de produtos:** apresentação de buquês com imagens, nomes e preços.
- **Identidade visual:** combinação de cores suaves, tipografia elegante e elementos delicados.
- **Organização do CSS:** separação dos estilos em arquivos para facilitar a manutenção do projeto.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Git e GitHub

## 🎯 Objetivos de aprendizado

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento front-end e tem como objetivos praticar:

- Estruturação semântica com HTML5.
- Estilização e organização de código CSS.
- Desenvolvimento de layouts responsivos com media queries.
- Utilização de Flexbox para organização e alinhamento dos elementos.
- Criação de um menu responsivo utilizando HTML e CSS.
- Organização dos estilos em arquivos separados.
- Aplicação de conceitos de design para construir uma interface visualmente consistente.

## 🚀 Como visualizar o projeto

1. Acesse o repositório no GitHub.
2. Clique no botão **Code** e selecione **Download ZIP**, ou clone o repositório utilizando o Git.
3. Extraia os arquivos, caso tenha baixado o ZIP.
4. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um ambiente de desenvolvimento para visualizar a página.

## 💗 Sobre o projeto

Petal & Poá é um projeto pessoal de estudo, desenvolvido para colocar em prática os conhecimentos adquiridos em HTML5 e CSS3.

Mais do que construir uma página, o objetivo foi exercitar a organização do código, a atenção aos detalhes visuais e a criação de uma interface responsiva, transformando uma ideia em um projeto próprio.
